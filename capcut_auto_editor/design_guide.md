> **주의**: 요청서에는 이 문서가 "별도 제공"으로 되어 있었으나 전달받지 못해
> 도구 쪽에서 작성했습니다. 원본 가이드가 있다면 **이 파일의 토큰 값만 교체**하십시오.

> 그 블록만 바꾸면 전체 UI가 따라옵니다.

> 가이드에 없는 색·간격·글꼴 크기를 **임의로 만들지 마십시오.**

## 5. 레이아웃

```
┌───────────────────────────────────────────────────────────┐
│ 헤더 56px   제목 · 세션명 · [새 세션] [세션 목록]            │
├──────────────┬────────────────────────────────────────────┤
│ 좌측 네비     │  우측 작업 영역                              │
│ 248px 고정    │  최대 980px, 좌우 여백 --sp-5               │
│              │                                            │
│ 0차 프로젝트   │  ┌ 카드 ────────────────────────────────┐  │
│ 캘 자막스타일 │  │ 섹션 제목                              │  │
│ 1차 컷 편집   │  │ 내용                                   │  │
│ 2차 자막      │  └──────────────────────────────────────┘  │
│ 3차 트랜지션  │                                            │
│ 4차 내보내기  │                                            │
│ 5차 세로영상  │                                            │
├──────────────┴────────────────────────────────────────────┤
│ 로그 패널 (접기/펴기, 기본 접힘, 최대 높이 220px)             │
└───────────────────────────────────────────────────────────┘
```

- 좌측 항목은 **완료 / 진행 중 / 잠김** 세 상태를 갖고,
  잠김이면 흐리게 표시하고 **잠긴 이유를 툴팁과 본문 상단에 함께** 씁니다.
- 단계 아이콘 외에는 이모지를 쓰지 않습니다.

## 6. 상태 표현

| 상태 | 표시 |
|---|---|
| 완료 | 좌측 항목에 `--ok` 점, 본문 상단에 초록 요약줄 |
| 진행 중 | 진행 막대 + **현재 항목명** + 경과 시간 |
| 잠김 | 버튼 `disabled` + 그 아래 한 줄로 이유 |
| 경고 | `--warn` 테두리 배너. 진행은 막지 않음 |
| 차단 | `--danger` 테두리 배너 + 해당 버튼 비활성 |

## 7. 문구 톤

- 전부 한국어. 존댓말. 명령형보다 서술형.
- 실패 메시지는 **무엇이 / 왜 / 무엇을 하면 되는지** 세 가지를 모두 적습니다.
  - 나쁨: `작업 실패`
  - 좋음: `캡컷이 실행 중이라 드래프트를 쓸 수 없습니다. 캡컷을 완전히 종료한 뒤 다시 눌러 주세요. (감지된 프로세스 7개)`
- 숫자는 **요청한 값이 아니라 파일에서 다시 확인한 값**을 씁니다.
