# 캡컷 자동 편집기

수출입 물류(포워딩) 유튜브 채널 운영자를 위한 로컬 편집 보조 도구입니다.
롱폼 영상을 넣으면 무음·필러·말더듬을 찾아 **검수용 목록으로** 올리고,
검수를 마친 결과로 캡컷 드래프트를 만들어 줍니다. 자막·트랜지션·효과음·세로 영상까지
같은 세션 안에서 이어서 작업합니다.

**자동으로 잘라내고 끝내는 기능은 없습니다.** 모든 자동 판정은 사용자 검수를 거칩니다.

---

## 1. 설치

### 1.1 준비물

| 항목 | 버전 | 비고 |
|---|---|---|
| Windows | 11 | |
| Python | **3.11** | 3.12 이상은 미검증 |
| ffmpeg / ffprobe | Gyan.FFmpeg 9.0 | `winget install Gyan.FFmpeg` |
| 캡컷 | **9.3.0.3969 (beta)** | 검증된 버전 |

### 1.2 설치

```powershell
winget install Gyan.FFmpeg
py -3.11 -m pip install -r requirements.txt
```

`faster-whisper`는 Silero VAD를 onnxruntime으로 내장 실행하므로 **torch가 필요 없습니다**
(약 2.5GB 절감).

> **`requirements.txt`를 고칠 때 주의**: 이 파일은 **ASCII만** 써야 합니다.
> pip는 이 파일을 **시스템 로케일 코덱**(한국어 윈도우는 cp949)으로 읽기 때문에,
> UTF-8로 저장된 한글 주석이 들어 있으면 설치가 이렇게 실패합니다.
>
> ```
> UnicodeDecodeError: 'cp949' codec can't decode byte 0x80 in position 4
> ```
>
> 한국어 설명은 이 README에 두십시오. `tests/test_packaging.py` 가 이를 검사합니다.

설치가 막히면 파일 없이 직접 지정해도 됩니다.

```powershell
py -3.11 -m pip install fastapi "uvicorn[standard]" python-multipart pycapcut==0.0.3 faster-whisper==1.2.1 rapidfuzz psutil pymediainfo imageio uiautomation
```

### 1.3 실행

```powershell
py -3.11 run.py
```

또는 `캡컷 자동 편집기 실행.bat` 을 더블클릭합니다.
서버가 뜨고 브라우저가 자동으로 열립니다 (기본 `http://127.0.0.1:8760/`).

> **bat 파일을 고칠 때 주의**: 이 파일은 **CP949(ANSI)** 로 저장되어 있습니다.
> 한국어 윈도우 cmd는 배치 파일을 코드페이지 949로 읽습니다. UTF-8로 저장한 뒤
> 파일 안에서 코드페이지를 65001로 바꾸면 cmd가 읽던 위치를 잃고 **아무 메시지 없이
> 즉시 종료**됩니다(창이 깜빡하고 사라짐). 인코딩을 ANSI로 유지하고 코드페이지 변경 명령을
> 넣지 마십시오.

## 2. 쓰는 순서

좌측 네비게이션 순서대로 진행합니다. 선행 단계가 끝나지 않으면 버튼이 잠기고 **잠긴 이유**가 표시됩니다.

| 단계 | 하는 일 |
|---|---|
| **0차 프로젝트 준비** | 원본 영상 여러 개 선택(순서 변경/제거), 해상도·fps·길이 확인, 캡컷 실행 감지, 백업 |
| **자막 스타일 캘리브레이션** | 캡컷에서 만든 참조 드래프트의 자막 스타일과 트랜지션을 그대로 가져옵니다 |
| **1차 컷 편집** | 무음 감지 → 음성 인식 → 컷 후보(무음/필러/반복) 검수 → 드래프트 생성 |
| **2차 자막 생성** | 대본 정렬, 용어 사전, 한 줄 자막 생성 → 검수 → 드래프트에 주입, SRT 내보내기 |
| **3차 트랜지션·효과음** | 이미지 클립 감지, 트랜지션 적용, 효과음 배치 |
| **4차 내보내기·문구** | 캡컷 내보내기 안내, 마케팅 문구 프롬프트 조립 |
| **5차 세로용 영상** | 구간 선택 → 1080x1920 드래프트 생성, 쇼츠/릴스 문구 프롬프트 |

### 2.1 캘리브레이션을 꼭 먼저 하십시오

pyCapCut이 만드는 텍스트 소재는 캡컷 원본보다 **필드가 91개 적습니다.**
빈 껍데기에 스타일만 얹으면 자막이 화면에 나타나지 않거나 배경이 빠집니다.
그래서 이 도구는 **캡컷 원본 소재를 통째로 저장해 두고 글자만 갈아 끼웁니다.**

캡컷에서 자막 하나와 트랜지션 하나를 직접 만든 프로젝트를 하나 준비해 두면
캘리브레이션 한 번으로 둘 다 가져옵니다.

### 2.2 드래프트를 건드리는 작업은 캡컷을 완전히 종료하고

캡컷은 프로젝트를 **메모리에 들고 있다가 저장할 때 파일을 통째로 덮어씁니다.**
켜진 상태로 이 도구가 JSON을 고치면 작업이 사라집니다.
도구가 작업 전과 **작업 직후에도** 프로세스를 검사해 차단하거나 경고합니다.

이미 열어 둔 프로젝트는 **완전히 종료했다가 다시 열어야** 반영된 내용이 보입니다.

**예외**: 4차의 자동 내보내기만 캡컷이 실행 중이어야 합니다 (§4 참고).

## 3. 자주 겪는 증상과 원인

증상과 원인이 멀리 떨어져 있는 것들입니다. 이 도구는 대부분을 미리 막지만,
직접 손댈 때 참고하십시오.

| 증상 | 원인 | 도구의 대응 |
|---|---|---|
| 진행률 2%에서 멈춤 | ffmpeg stderr 파이프 4KB 버퍼 데드락 | 모든 호출에 `-hide_banner` + stderr 전용 배수 스레드 |
| 자막이 파일엔 있는데 화면에 안 보임 | `track_render_index` 충돌 | 저장 후 트랙 순서대로 재매김 |
| 흰 배경이 안 나옴 | `check_flag` 배경 비트(+16) 없음 / `background_style`이 0 | 31로 맞추고 style을 1 이상으로 강제 |
| 경로에 `����` | 자식 프로세스 stdout이 cp949 | 자식 `reconfigure` + 부모 `PYTHONIOENCODING` + 깨짐 감지 알림 |
| bat 더블클릭하면 창만 깜빡 | UTF-8 저장 + 코드페이지 변경 | bat을 CP949로 저장, 코드페이지 변경 없음 |
| 말끝이 잘려 들림 | 무음 시작 쪽 여유 부족 | 앞뒤 여유를 **따로** 둠 (기본 꼬리 0.35초 / 머리 0.15초) |
| 자막 싱크가 안 맞음 | 드래프트와 컷 설정 불일치 | **컷 서명**을 대조해 어긋나면 자막 주입을 차단 |
| `pip install -r` 이 `UnicodeDecodeError: 'cp949'` 로 실패 | pip가 requirements.txt를 로케일 코덱으로 읽음 | requirements.txt를 ASCII로만 유지 (§1.2) |
| 세로 영상 자막이 화면 가운데에 | 가로에서 읽은 정규화 좌표를 픽셀로 환산 | 세로 캔버스에서는 정규화 값을 유지 (실측 -0.7394) |

자세한 근거는 `docs/investigation.md` 에 있습니다.

## 4. 자동 내보내기 (미검증 · 기본 꺼짐)

4차의 자동 내보내기는 pycapcut이 **캡컷 UI를 직접 조작**하는 방식입니다.
소스를 읽어 확인한 제약이 세 가지 있습니다.

1. 창 탐색 조건이 중국어 제목 `"CapCut专业版"` 으로 **하드코딩**되어 있습니다.
   한국어/영어 캡컷에서는 창을 찾지 못합니다.
2. pycapcut 문서에 **"캡컷 6 이하만 지원"** 이라고 적혀 있습니다. 검증 대상은 9.3.0.3969입니다.
3. `import pycapcut` 으로는 접근할 수 없어 `pycapcut.jianying_controller` 를 직접 임포트합니다.

**따라서 기본값은 꺼짐이고, 확인 체크박스를 눌러야 시도할 수 있습니다.**
실패해도 드래프트는 그대로 남으므로 캡컷에서 직접 내보내면 됩니다.

## 5. 미검증 항목

아래는 **개발 환경에서 확인하지 못한** 것들입니다. 처음 쓰실 때 직접 확인해 주십시오.

### 5.1 윈도우/캡컷이 있어야 확인 가능한 것

| 항목 | 상태 | 확인 방법 |
|---|---|---|
| 캡컷 드래프트 폴더 자동 탐지 | **미검증** | 0차 화면 상단에 경로가 뜨는지 확인. 못 찾으면 직접 지정하는 입력창이 나옵니다 |
| 드래프트가 캡컷 프로젝트 목록에 뜨는지 (3.12) | **미검증** | 1차 실행 후 캡컷을 열어 목록 확인 |
| 자막이 캡컷 화면에 실제로 보이는지 (3.3/3.4) | **미검증** | 2차 실행 후 캡컷에서 재생. 흰 배경 + 검정 글씨 + Pretendard |
| 캡컷 프로세스 락 동작 (3.13) | **미검증** | 캡컷을 켠 채로 버튼을 눌러 차단되는지 확인 |
| ffmpeg stderr 4KB 데드락 (3.14) | **부분 검증** | 배수 스레드와 `-hide_banner` 주입은 테스트로 확인. 실제 Gyan 빌드의 배너 크기는 미확인 |
| cp949 경로 깨짐 (3.15) | **부분 검증** | 깨짐 감지 로직은 테스트로 확인. 실제 cp949 환경 재현은 미확인. 재현하려면 `PYTHONIOENCODING`을 **지우고** 탐색기에서 bat으로 띄워야 합니다 |
| bat CP949 동작 (3.16) | **미검증** | 더블클릭해 창이 남는지 확인 |
| 트랜지션이 의도대로 보이는지 | **미검증** | pyCapCut은 베타입니다. 적용 후 **캡컷에서 육안 확인이 필요합니다** |
| 세로 오버레이 scale 1.8 / y -0.078125 | **요청서 실측값 채택** | 5차 실행 후 캡컷에서 여백을 확인하고 슬라이더로 조정 |
| 자동 내보내기 | **동작하지 않을 가능성 높음** | §4 참고 |

### 5.2 음성 인식 관련

| 항목 | 상태 |
|---|---|
| faster-whisper CPU 동작 | **미검증** (개발 환경에 미설치) |
| 모델 다운로드 진행률 표시 | **미검증** — hub + xet staging 폴더 크기로 **추정**합니다. 실제 값과 다를 수 있습니다 |
| 청크 재시작 | 로직은 구현, 실제 중단/재개는 미검증 |

첫 실행 시 `medium` 모델 약 1.5GB를 내려받습니다. 0차 화면에 미리 안내가 뜹니다.
NVIDIA GPU가 없으면 CPU로 돕니다(Intel Arc는 CTranslate2 미지원). 기본 모델을
`large-v3`가 아니라 `medium`으로 둔 이유입니다.

### 5.3 확인된 것

개발 환경(Linux, Python 3.11.15, pycapcut 0.0.3)에서 **실제로 실행해 확인**한 것들입니다.

- pyCapCut으로 드래프트를 만들고 → 자막을 주입하고 → 트랜지션을 붙이고 →
  세로 드래프트를 만드는 전 과정이 동작합니다.
- 만들어진 `draft_content.json`에서 `check_flag=31`, `background_style=1`,
  `track_render_index`가 트랙 순서대로, 폰트 절대 경로가 소재와 `content.styles[0].font.path`
  양쪽에, 소재 필드 31개(pyCapCut 기본 15개), 캡컷 원본 필드 보존을 확인했습니다.
- 컷 서명 불일치 시 자막 주입이 실제로 차단됩니다.
- 세로 드래프트의 `canvas_config.ratio`가 `"9:16"`으로 교정됩니다.
- 자동 테스트 99개가 통과합니다 (`py -3.11 -m pytest tests -q`).

```
capcut_auto_editor/
  run.py                      서버 기동 + 브라우저 오픈

  app/
    main.py                   FastAPI 앱
    config.py                 경로 탐지, 설정, 사전

  assets/sfx/                 효과음 wav를 여기에 넣습니다

  data/                       설정, 사전, 스타일 프로파일, 세션, 작업 파일
  backups/                    단계 실행 전 드래프트 스냅샷
  logs/                       날짜별 로그
  docs/investigation.md       착수 전 조사 기록
  tests/                      자동 테스트
```

## 9. 알려진 제약

- 캡컷은 공식 자동화 API를 제공하지 않습니다. pyCapCut은 드래프트 JSON 구조를
  리버스 엔지니어링한 **비공식 도구**이며 캡컷 업데이트로 언제든 깨질 수 있습니다.
  검증 조합과 다르면 0차 화면에 경고 배너가 뜹니다.
- pyCapCut은 베타 단계입니다. 애니메이션·효과·트랜지션이 의도대로 적용되지 않는
  사례가 보고되어 있으므로 **적용 후 캡컷에서 육안 확인이 필요합니다.**
- 자동 내보내기는 Windows 전용이고 캡컷 버전·UI 언어에 민감합니다 (§4).
- 필러워드와 말더듬 자동 감지는 완벽할 수 없습니다. **검수 UI가 이 도구의 핵심입니다.**
- 음성 인식은 오타를 냅니다(캡컷→"캡커스", 컷→"컵"). 용어 사전과 검수로 보완하십시오.
- 트랜지션 전체 목록(1137개)의 이름은 중국어입니다. 한국어 UI 이름과 매칭되지 않으므로
  원하는 트랜지션은 캡컷에서 한 번 적용한 뒤 **가져오기**로 받아 오십시오.
- 외부 LLM API를 쓰지 않습니다. 문구 생성은 **완성된 프롬프트 텍스트**를 만들어
  클립보드 복사와 txt 저장으로 제공합니다.
