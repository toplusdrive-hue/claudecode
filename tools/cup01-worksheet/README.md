# CUP01 · Small Steps Every Morning — 학습지 편집기

학생용 아침 영어 문장 학습지를 만들고 A4 PDF로 뽑는 단일 파일 도구입니다.
`index.html`을 브라우저로 열기만 하면 됩니다. 설치·빌드·서버 모두 필요 없습니다.

```
open tools/cup01-worksheet/index.html      # macOS
xdg-open tools/cup01-worksheet/index.html  # Linux
```

## 화면

왼쪽에서 내용을 고치면 오른쪽 A4 미리보기가 바로 따라옵니다. 미리보기는 실제 인쇄물과
같은 210×297mm이고, 내용이 한 쪽을 넘으면 페이지 위에 경고가 뜹니다.

## 학습지 구성

| 영역 | 내용 |
|---|---|
| 머리말 | 코스 코드, 프로그램명, Day 번호, 날짜·이름·학습 시간 기입란 |
| 오늘의 초점 | 오늘의 주제 / 오늘의 목표 |
| 문장 | 번호, 영어 문장, 한글 뜻, 한글 발음, 쉐도잉 횟수 ○, 영어 4선 따라쓰기 줄 |
| 오늘의 확인 | 한글 뜻을 보고 영어로 쓰는 문항 (문장에서 고르게 뽑음) |
| 마무리 | 듣기·따라 말하기·따라 쓰기·안 보고 말하기 체크, 한 줄 기록, 확인란 |

## 세 가지 모드

- **학습** — 영어 문장·뜻·발음을 모두 보여 주고 아래 줄에 따라 씁니다.
- **덮어쓰기** — 첫 줄에 연한 영어 글씨가 깔립니다. 그 위를 덮어쓰고 나머지 줄엔 스스로 씁니다.
- **점검** — 한글 뜻만 보고 영어 문장을 직접 씁니다. 발음·쉐도잉 칸은 숨깁니다.

같은 문장으로 세 종류 학습지를 뽑을 수 있으니, 월요일엔 학습·수요일엔 덮어쓰기·금요일엔
점검으로 돌려 쓰면 됩니다.

## PDF로 저장하기

`인쇄 · PDF 저장` → 대상을 **PDF로 저장**, 용지 **A4**, 배율 **100%**, 여백 **없음**,
**배경 그래픽** 켜기. 여백을 "기본"으로 두면 학습지가 축소되어 4선 줄 간격이 어긋납니다.

흑백 프린터로 여러 장 뽑을 땐 `흑백 인쇄용 (잉크 절약)`을 켜세요.

## 문장 일괄 입력

`일괄 입력`에 한 줄에 한 문장씩, 세로 막대로 나눠 붙여 넣습니다. 발음은 생략해도 됩니다.

```
Good morning! Did you sleep well? | 좋은 아침! 잘 잤어? | 굿 모닝! 디쥬 슬립 웰
One small step is enough. | 작은 한 걸음이면 충분해.
```

## 데이터

편집 중인 내용은 브라우저(localStorage)에 자동 저장됩니다. 다른 기기나 다른 선생님에게
넘길 땐 `JSON 내보내기`로 복사해 파일로 보관하고, 받은 쪽은 그 JSON을 붙여 넣고
`JSON 불러오기`를 누릅니다.

```jsonc
{
  "options": {
    "mode": "study",     // study | practice | test
    "trace": 1,          // 따라쓰기 줄 수 (0~4)
    "shadow": 3,         // 쉐도잉 ○ 개수
    "perPage": 6,        // 페이지당 문장 수
    "fs": 1,             // 글자 크기 배율
    "quiz": 3,           // 오늘의 확인 문항 수
    "guide": true,       // 영어 4선 안내선
    "pron": true,        // 한글 발음 표기
    "reflect": true,     // 마무리 기록 칸
    "mono": false,       // 흑백 인쇄용
    "accent": "#2E6F6A",
    "scope": "one"       // one(현재 Day) | all(전체 Day)
  },
  "active": 0,
  "sheets": [
    {
      "course": "CUP01",
      "program": "Small Steps Every Morning",
      "tagline": "아침 5분, 오늘의 영어 문장",
      "day": "01", "date": "", "minutes": "10분",
      "theme": "아침 인사와 기분 표현",
      "goal": "인사 문장 6개를 보지 않고 말하기",
      "sentences": [
        { "en": "Good morning! Did you sleep well?", "ko": "좋은 아침! 잘 잤어?", "pr": "굿 모닝! 디쥬 슬립 웰" }
      ]
    }
  ]
}
```

`sheets` 배열에 Day를 계속 쌓을 수 있고, 인쇄 범위를 `전체 Day 이어서`로 두면 한 주치를
한 번에 뽑습니다.
