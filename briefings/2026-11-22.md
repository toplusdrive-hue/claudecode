```
▶ '틀어두기·흘려듣기' + 확신형 훅("~면 저절로/충분합니다")이 오늘 가장 강한 제목 공식
   근거: ⑤확신형 평균 조회수 = 256,048 (4개), 훅 없음 = 79,090 (24개) / ③틀어두기 평균 = 143,162 (13개), 소비방식 없음 = 67,939 (21개)

▶ '100문장'은 가장 흔하지만 가장 안 뜨는 숫자 — 100을 피하고 비정형 큰 숫자로
   근거: ①100(100~150) = 17개, 중앙값 68,828 / ①151~299 = 2개, 중앙값 381,576 / ①1000+ = 3개, 중앙값 154,288 (표본 작음 주의)

▶ 시니어·왕초보 + 소형 채널이 채널 규모를 수십 배 넘는 조회수를 냄 — 진입 장벽이 낮은 주제
   근거: 신흥 채널(구독 1만 미만·채널대비 2.0+) = 5개, 최고 '딱20 영어' 채널대비 = 61.5배(구독 8,760 → 539,005회) / 상위 3채널 점유율 = 44.8% (과점 아님)
   우리가 할 것: 레벨 슬롯에 '시니어' 또는 '60대'를 넣고 느린 낭독 + 한글 발음 표기 포맷으로 1편 테스트
```

- 시청자가 직접 타임스탬프(반복 훈련 시작 지점)를 댓글로 공유 → 챕터 수요 확인

**반복 불만**
- AI 음성 대신 선생님 목소리로 읽어 달라 (AI 낭독 거부감)
- 장시간 영상의 중간 광고가 너무 많다
- 문장이 너무 쉽다 / 반대로 실제 속도는 따라가기 어렵다 (난이도 양극)
- 고정 댓글·UI가 자막을 가림, 한국어 음성 오녹음 정정 공지

**요청·칭찬에서 드러난 수요**
- 다음 편(2탄) 요청, "매일 올려 달라"
- **천천히 또박또박 읽는 것**에 대한 칭찬이 여러 영상에서 반복 → 느린 속도 수요
- 출근길·지하철·런닝머신·설거지·운전 중에 틀어둔다는 사용 맥락이 반복 → '틀어두기' 소비 방식이 실제 행동과 일치
- 60~80대 시청자의 자기소개형 댓글 다수 → 시니어 수요 실재

**감정 톤 (키워드 기반 대략 분류, 209개)**: 긍정 128 (61%) / 중립 62 (30%) / 부정 19 (9%)
