- 우리가 바꿀 것: 원인 진단 + 해결 루틴 콘텐츠 기획
- 제목 초안: 듣기는 되는데 말이 안 나오는 진짜 이유 / 배운 표현이 입에 안 붙는 이유, 이렇게 바꾸세요

## 방법론 메모

- '영어' 단독 검색에서만 매칭되고 다른 키워드에는 매칭되지 않은 연예/이슈성 클립 10건은 학습 콘텐츠 트렌드를 왜곡하므로 TOP20/패턴/채널 분석에서 제외(키워드별 원자료에는 포함)
- API 호출 예산(40회) 제약으로 댓글 수집은 주 키워드 상위 조회수 영상 위주 12건(232개 댓글)에 한정
- 채널 대비 성과는 검색에 잡힌 대표 영상 1건 기준이며, 다건 영상 보유 채널은 대표성이 제한적일 수 있음
