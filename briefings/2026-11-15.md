| 5 | 딱 40문장이면 식당·카페 주문은 끝 \| 통째로 외우는 왕초보 해외여행 영어 | ①~50 + ②여행 + ③통째로 외우기 + ⑤확신형 + ⑦왕초보 | ~50+확신형 평균 193,123 / 통째로 외우기+확신형 평균 255,076 |

- 1~3번은 7단계의 '아무도 안 쓴 조합'을 썼다. 모든 초안은 슬롯 조합만 빌렸고 기존 제목 문구는 복제하지 않았다.

## 10. 핵심 포인트 3가지

```
▶ 명령형("외우세요")보다 확신형("~만 틀어두면 됩니다")이 2배 가까이 강하다
   근거: ⑤확신형 중앙값 = 124,068 (n10), ⑤명령형 중앙값 = 79,733 (n24) / ③틀어두기+⑤확신형 평균 = 219,496
   우리가 할 것: 다음 영상 제목의 훅을 명령형에서 확신형 '틀어만 두면 ~됩니다'로 바꾸고, 첫 8글자에 대상(왕초보·시니어)을 넣는다
```
```
▶ 문장 수는 100 → 300까지 키울 때 효과가 가장 크고, 500 이상은 확실하지 않다
   근거: ①200~599 중앙값 = 91,431 vs ①51~199 = 72,786 / 주아쌤 100장면→300장면 일평균 844 → 4,613, 200문장→500문장 4,521 → 3,272
   우리가 할 것: 다음 편은 '200~300문장'으로 잡고, 러닝타임은 30~60분(중앙값 87,852, 구간 1위)에 맞춘다
```

▶ 여행·비즈니스 '틀어두기'형은 비어 있는 시장이다
   근거: TOP50 내 ②여행+③틀어두기/흘려듣기 = 0건, ②비즈니스 = 0건 vs 여행 평균 조회수 = 115,578 (TOP50 평균 103,578 상회)

## 11. 데이터 노트

- 모든 수치는 2026-11-15 수집 시점의 YouTube Data API v3 응답 기준이다. 일평균 = 조회수 ÷ max(경과일, 1)
- 슬롯 태깅은 정규식 규칙으로 했다(복수 태깅). 조합 표는 주 태그 기준이다. 상세 규칙과 원본 지표는 같은 날짜의 `.json` 파일에 있다
- 일부 숫자 '10개/30개'(꼬리 공식)는 문장 수가 아니라서 ①에서 '없음'으로 처리했다
- 감정 톤은 키워드 규칙 기반이라 대략적인 값이다
