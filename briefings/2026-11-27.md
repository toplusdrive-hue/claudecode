## 11. 데이터 노트

- 모든 수치는 2026-11-27 수집 시점의 YouTube Data API v3 응답으로 계산했습니다. 추정치는 없습니다(댓글 감정 비율만 직접 읽고 분류한 대략치입니다).
- 슬롯 태깅은 제목 정규식 규칙으로 했습니다. 한 제목에 값이 여러 개면 복수로 태깅했고, 조합 표는 각 슬롯의 첫 값을 기준으로 했습니다.
- 채널대비 성과 = 조회수 ÷ 현재 구독자 수 (구독자 비공개면 데이터 없음).
- 표본이 5개 이하인 구간(1000+, 3시간+, 틀어두기 × 금지형 등)은 방향성 참고용입니다.
